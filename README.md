# Subly

SaaS subscription billing system: plans and pricing, subscriptions with trials and proration, automated invoicing,
payments with dunning, and signed webhooks. Sibling project to [PayFlow](../payflow).

**Example:** a software company bills its customers monthly or yearly. Subly prorates mid-cycle plan changes,
charges each cycle, retries failed payments before cancelling, and sends webhooks so the product can grant or
restrict access.

## Stack

| Concern | Choice |
|---|---|
| Runtime | Java 25, Spring Boot 4.1 |
| Build | Maven (multi-module) |
| Data | PostgreSQL 16, Spring Data JPA, Flyway |
| Cache / locks | Redis 7 |
| Events | Kafka (KRaft), transactional outbox |
| Auth | Hashed API keys → short-lived JWT (HS256) |
| Observability | Actuator, Micrometer → Prometheus, Grafana, ECS JSON logs |
| Tests | JUnit, AssertJ, Testcontainers, JaCoCo |
| Delivery | Docker, GitHub Actions (self-hosted runner), k3s |

## Layout

```
subly/
├── subly-domain/          Pure domain: Money, state machines, enums. No Spring.
├── subly-application/     Use cases + ports (IdGenerator, DomainEventPublisher, ...)
├── subly-infrastructure/  JPA, Flyway migrations, Redis, Kafka, mock payment provider
├── subly-api/             Spring Boot app: controllers, security, filters, config
├── docs/adr/              Architecture decisions
├── docs/diagrams/         Sequence + ER diagrams (Mermaid)
├── k8s/                   Manifests for the homelab k3s cluster
├── observability/         Prometheus scrape config, Grafana provisioning
├── docker-compose.yml     Local Postgres, Redis, Kafka, Prometheus, Grafana
└── Dockerfile             Multi-stage, layered, non-root
```

Dependency rule: `api → infrastructure → application → domain`. Nothing points outwards.

## Getting started

Prerequisites: JDK 25, Maven 3.9+, Docker.

```bash
mvn -N wrapper:wrapper     # one-time: generates ./mvnw
make up                    # Postgres :5433, Redis :6380, Kafka :9094, Prometheus :9091, Grafana :3001
make run                   # API on :8080, Flyway applies V1 on startup
curl localhost:8080/actuator/health
```

Ports are offset from PayFlow's so both stacks can run at once.

| Command | What it does |
|---|---|
| `make test` | Unit tests |
| `make verify` | Unit + Testcontainers integration tests + coverage report |
| `make image` | Build the container image |
| `docker compose --profile app up --build` | Run everything, including the API, in containers |

## Conventions

- Money is `BigDecimal` via `Money`; never `float`/`double`.
- IDs are generated by the application.
- Balances are computed from `ledger_entry`, never stored.
- Every state change that matters writes an `outbox_event` in the same transaction.
- Health and metrics endpoints are anonymous; everything under `/v1` needs a JWT.
